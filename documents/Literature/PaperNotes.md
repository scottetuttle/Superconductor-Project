# Summary

There is a superconducting state ψ with the definition 
ψ(r,t)=∣ψ∣exp(iθ)

∣ψ∣ = superconducting amplitude/density
θ = superconducting phase

For equilibrium state it is defined ∣ψ∣={1−T/Tc,T<Tc,0,T≥Tc}

This explains the desnity of the superconductor at equilibrium as temperature dependent.

For the Dynamics of TDGL we have a core equation

u dpsi/dt = D^2 psi + (1 - T/Tc) psi - |psi|^2 psi
	​
There is a spatial/kinetic term

D = nabla - i A

This is what allows the superconductor to respond to electromagnetic fields

D^2 psi = (nabla - i A)^2 psi

Then a linear superconducting term

(1 - T/Tc) psi

This is what drives the system towards superconductivity below Tc and toward the normal state above Tc

Then a nonlinear saturation
	​
-|psi|^2 psi

This prevents the order parameter from growing without bound and produces the finite equilibrium amplitude


The current solving method is done as a time-stepping approach essentially adding a small change in time and solving for the infintesimal change then adding it to the previous state.
