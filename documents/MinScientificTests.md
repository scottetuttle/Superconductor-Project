"When these pass, can we reasonably call the SHS physics implementation scientifically viable?"

That would constitute a very credible foundational scientific validation suite.

It would still not mean "SHS is proven correct for every superconducting phenomenon."

But it would mean:

The numerical implementation of the chosen physical models has been independently and quantitatively validated across their fundamental regimes.

That is the standard I think we should aim for.
